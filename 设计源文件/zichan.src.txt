## 01 改版说明

**第二稿按三份设计文档改为完整版。场景、建筑和道具仍做 3D 低模，用卡通着色、描边和水彩后处理渲成手绘风格；人物改为纸片人，图标和界面是 2D。**

- 范围改为完整版：五级声望、23 道菜和 7 种酒、34 种食材和调味、小二与学徒、6 位名流和仙人等特殊客人、二楼与雅间扩建、时空门逐级扩容。
- 做菜是"放进灶台、倒计时、出炉"，不做切菜和完整烹饪动画；灶台分初、中、高三档。
- 人物做纸片人：2D 分层立绘放进 3D 场景，能走、坐、端菜、追人；对话另配半身像。客人要进门、入座、离开，小二要上菜、追跑单，学徒守灶台，只有立绘不够用。
- 优先级按游戏进度排：P0 是一级的内容（前两关、简单菜、一楼、集市前三个摊位、时空门首次升级），P1 是二级、三级，P2 是四级、五级和正店阶段。
- 已完成样张不变：纹璃宫灯，497 面全四边面，三渲二 + 水彩，文件在仓库 WhiteModel/。
- 数量以设计文档为准；设计再改时，这张表跟着改。

## 03 三渲二建模规范（首版）

**3D 资产统一按下表制作；数值是首轮建议，以纹璃宫灯（497 面）为参照，做几件之后再调。**

%cols 16 84
| 项目 | 规范 |
| 面数 | 小道具 ≤ 500 面；中型道具（灶台、柜台、船、摊位）≤ 1,500 面；建筑与虹桥 ≤ 3,000 面 |
| 布线 | 全部四边面；硬边至少做一道倒角（圆角），配合 Weighted Normals，让明暗和描边在转角处连续 |
| 删面 | 永远看不见的面删掉：插进别的零件的部分、被遮住的顶面、固定机位下看不到的背面；贴地和轮廓处要封口，否则描边会断 |
| 尺寸与导出 | 单位米；FBX Y 轴朝上；原点在底部中心；命名 SM_名称 |
| 材质 | 按颜色分材质槽（如石、木、琉璃），每槽一个亮色和一个阴影色；不做 PBR 贴图，水彩质感由后处理统一加 |
| 人物（纸片人） | 2D 分层立绘贴在面片上，始终朝向镜头；头、躯干、手臂、腿分层，方便做走路、端菜等简单动作；描边颜色和粗细与三渲二描边一致；脚下加一块阴影贴片 |
| 交付 | 源文件（.blend 或 .ma）＋ FBX ＋预览图（白模、布线、三渲二） |

做法可参考仓库里的 WhiteModel/build_wenli_gongdeng.py（建模与减面）和 WhiteModel/watercolor.py（水彩效果）。

## 04 推荐制作顺序

**先锁定镜头、线条粗细、配色和纸片人比例，再按 P0、P1、P2 批量制作；这样后期不会因为风格、面数或点击范围变化而大量返工。**

%cols 22 78
| 步骤 | 内容 |
| 第 1 步｜视觉基准 | 一楼前堂与后厨草图、UI 风格样张、三渲二效果样张（已有纹璃宫灯）、一张纸片人放进 3D 场景的样张；确认镜头、画面比例、线条粗细、配色和人物大小 |
| 第 2 步｜白模 | 一楼（前堂、后厨 12 个灶台位）、初等灶台、桌椅、时空门、集市前三个摊位先出白模审形，再减到面数预算内 |
| 第 3 步｜P0 上色进引擎 | 定每个材质的亮色和阴影色，导入 Unity 接上三渲二效果；同时做一级的 7 道菜图、18 个图标、厨师与小二及顾客的纸片人、经营与系统界面、科普卡 |
| 第 4 步｜P1 | 二级、三级的内容：中等灶台、学徒、中等菜和可乐鸡翅、酒水、二楼与雅间及扩建过场、名流与仙人、卷轴地图与博物馆界面、其余成就 |
| 第 5 步｜P2 与打磨 | 四级、五级与正店阶段：高等灶台、高等菜、现代酒、门面升级、正店管事与皇帝；最后统一描边和水彩参数 |

## 05 每类文件怎么交

**3D 资产按建模规范交付，2D 资产沿用原清单的要求。**

- **3D 场景与道具**：每件一个文件，交源文件、FBX 和预览图，名称与资产表一致。
- **地图**：在 Unity 里拼成横向场景；五处点击目标是独立物体，能单独显示、隐藏和高亮。远景如用 2D 画面，按层交付。另出一张三渲二横向全景渲染图，给博物馆模式当标注底图。
- **人物（纸片人）**：交分层透明 PNG（头、躯干、左右手臂、腿各一层）和一张合成预览，标出关节点；半身像另交。统一人物比例与视线方向；小二、学徒另交换色版。
- **图标与菜品**：每件资产单独导出透明 PNG，名称与库存/菜谱表保持一致；小尺寸显示时也要能辨认。菜品的次等、糊、仙味做成通用叠加层，不逐道重画。
- **招牌**：交不带字的底板，再选定一种书法字体；店名由程序实时写上。
- **界面**：按钮、卡片、边框、图标和文字层分开交付；不要把动态数值或中文说明写死在背景图片里。
- **博物馆模式**：五处标注位置以相对坐标记录，信息卡文字和来源链接单独保存；历史说明与游戏虚构内容用视觉标签区分。

## 06 暂不制作的资产

整座汴京地图、七十二家正店各自的独立场景（正店比拼的形式定了再加）、大量独立 NPC（同类客人靠换装和换色复用）、每道菜的完整烹饪动画（做菜用灶台倒计时和特效表现），以及一套与游戏地图重复的博物馆画卷。写实 PBR 材质不做；人物用纸片人，3D 角色的骨骼绑定与动画也不做。这些可以留在后续扩展计划中。

## 07 交付检查

- 一级能完整玩通：采购、验货、做菜出炉、上菜、结账、升级。
- 出炉倒计时和次等、完美、糊的判定一眼能看懂；可做份数和坏料丢弃都清楚。
- 现代食材、新菜解锁和时空门升级的变化明显。
- 纸片人在 3D 场景里的描边、明暗和比例与场景一致。
- 博物馆模式可以解释同一画面中的五处区域。
- 3D 资产面数在预算内、全部四边面；游戏机位下描边连续不断线，三渲二和水彩效果在所有资产上一致。

## 08 待定事项

**这些问题定下来之后，资产表和建模规范再更新一版。**

- ☑ 人物做 2D 立绘还是 3D？已定：纸片人，本版按此写。
- ☐ 游戏机位：纹璃宫灯用的是斜 45°、俯角约 27°，一楼前堂和后厨是否沿用？后厨 12 个灶台位能否在一个画面里放下？
- ☐ 面数预算：小道具 500 面已验证，灶台三档和建筑的上限做一两件后再定。
- ☐ 地图远景用 3D 还是 2D 画面？
- ☐ 水彩效果的强度（纹理、晕染、墨线粗细）以哪张画面为准？
- ☐ Unity 里的三渲二和水彩效果由谁实现、哪一周接入？
- ☐ 八周原型要交哪些内容（包括博物馆演示）？从 P0、P1 里挑。
- ☐ 门面升级（彩楼欢门）做不做？这是建议项。
- ☐ 正店比拼的场景和形式，等设计定了再补资产。
